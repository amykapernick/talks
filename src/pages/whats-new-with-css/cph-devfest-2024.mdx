<Slide type="split" size="xs" dir="vertical" split={['dark']}>
	```css
		.parent {
			background: chartreuse;

			.child {
				background: lemonchiffon;
			}
		}		
	```
	```css
		/* Renders out the same as */
		.parent {
			background: chartreuse;
		}

		.parent .child {
			background: lemonchiffon;
		}
		
	```
</Slide>

<Slide type="code" size="small" lines={['4']}>
	```css
		.parent {
			background: chartreuse;

			& .child {
				background: lemonchiffon;
			}
		}
		
	```
	<Notes slot="notes">
		- Don't need & anymore
	</Notes>
</Slide>
